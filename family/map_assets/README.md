# Self-hosted map assets (Protomaps basemaps)

Fonts and sprites from [protomaps/basemaps-assets](https://github.com/protomaps/basemaps-assets) (CC0 / public domain). Copied to the box map data directory by `scripts/lib/fetch-map-extract.sh`.

The regional `basemap.pmtiles` extract is **not** in git; it is generated on the server from `build.protomaps.com` (see [docs/MAP.md](../../docs/MAP.md)).
