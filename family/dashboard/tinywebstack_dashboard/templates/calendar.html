Android (DAVx5)

  1. Install DAVx5 from the Play Store.
  2. Add account → Login with URL and user name.
  3. Base URL: the server URL above; username and password as listed.
  4. When sync finishes, enable Family, Personal, and any other shared calendars you need.

iPhone / iPad (Apple Calendar)

  1. Settings → Calendar → Accounts → Add Account → Other → Add CalDAV Account.
  2. Server: your Nextcloud hostname (the part after https:// in the server URL).
  3. Username and password: as listed above. If needed, open Advanced and set Account URL to the principal URL.

Shared calendars on this home: Family (everyone), Parents (adults only), Kids (children + parents), plus your personal calendar.
