If this computer is lost

This page does not start a restore. There is no restore button. Restoring replaces family logins, chat, calendars, events, location history, family rules, and home settings on the computer you restore onto. People will need to sign in again. Encrypted chat on a new phone still needs the recovery key from the old phone.

YunoHost will not restore an app that is already installed, and restoring over this running page would be the wrong tool. Use a replacement computer:

  1. If the old box still turns on, copy the archive off it first. A file that is still only on the broken disk is not a recovery copy.
  2. Install Debian and YunoHost on the replacement computer. Do not run YunoHost’s first-time setup (postinstall). YunoHost’s own restore takes the place of that step.
  3. Put the archive at /home/yunohost.backup/archives/ on the new computer. The file name ends in .tar.
  4. As root on the new computer, restore that archive and nothing else. For a backup named below, the command is the name without .tar.
  5. Do not install chat, calendars, or events on the new computer before that restore.
  6. After it finishes, sign in at /family/ as a parent and check one chat, one calendar event, and one family event before you trust the new box. Then re-apply the TinyWeb family module if chat rules are missing. The steps for the person who maintains the box are in the operations guide.
