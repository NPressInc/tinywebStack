# TinyWeb brand assets (vendored)

Visual identity sourced from [https://tinyweb.win](https://tinyweb.win) (NPress, Inc.) for family-facing surfaces.

- `portal/` — YunoHost 12 user portal (SSO login) theming via supported domain config (`feature.portal.*`). `tinyweb-family-tile.png` is the **Family home** app-grid icon; `element-tile.png` is the Element Web tile for **operator/lab** Matrix debugging (vendored from Element desktop app icon) — families use the TinyWeb mobile app for chat.
- Dashboard assets live under `family/dashboard/tinywebstack_dashboard/static/tinyweb/` (same logos; served locally, not hotlinked).

Do not hotlink production URLs in the app; update vendored files when the public brand changes.
